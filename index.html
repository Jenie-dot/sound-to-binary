Explain It

  1. How does your app change a sound wave into binary?
    The app samples the wave at evenly spaced times, maps each sample's height to a digital level, and writes that level in binary using the selected number of bits.
  2. Which gives more detail: 2 bits or 6 bits? Why?
    Six bits gives more detail because it provides 64 possible levels, while 2 bits provides only 4 levels.
  3. Which test has the longest wavelength compared to frequency?
    The test with the lowest frequency has the longest wavelength because wavelength equals the speed of sound divided by frequency.
  4. What was the hardest stage to build, and how did you fix it?
    The hardest stage was converting each sampled height into a level and binary. I fixed it by calculating the number of levels first, rounding each sample to a valid level, and padding the binary values to the selected bit depth.
